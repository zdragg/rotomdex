# `rotomdex`

`rotomdex` is the Pokédex built for the terminal.

## Features
- Demand-driven asynchronous asset fetching
- Hotswappable versions
- Offline mode
- Designed for 80x24

## Usage

```bash
# Run in online mode
rotomdex

# Download assets required for offline mode
rotomdex --download

# Run in offline mode
rotomdex --offline
```
